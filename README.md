# HASERI — Ethiopian Local Services Marketplace

HASERI is a full-stack marketplace concept that helps people discover local service providers and connect with them. The project is designed around the needs of customers and service providers in Ethiopia.

## Core capabilities

- Discover local services and providers
- Post service requests and respond to opportunities
- Customer and provider workflows
- Real-time communication
- Reviews and reputation features
- Payment integration and transaction history
- Administrator moderation and platform management
- Location-aware service discovery

## Technology

- **Frontend:** Next.js 16
- **Backend:** Laravel 13
- **Data access:** Eloquent ORM
- **Database:** PostgreSQL
- **Integrations:** Chapa payments and Telegram notifications

## Project status

HASERI is an evolving team software engineering project. Feature availability and setup details may change as development continues. Check the source folders and project configuration before deploying.

## Getting started

1. Clone the repository.
2. Inspect the frontend and backend project directories.
3. Install the dependencies for each application using its package manager.
4. Configure local environment variables and database credentials.
5. Run database migrations and start the applications using their framework commands.

> Do not commit real API keys, database passwords, payment secrets, or other credentials. Use local environment files and provide safe example values in any shared configuration template.
